# ליזי – דמות זמנית (Placeholder)

דמות SVG פשוטה שנוצרה כדי שתוכלי להתחיל לעבוד עכשיו. כשיהיו איורים אמיתיים – מחליפים את הקבצים באותם שמות (או מעדכנים את הנתיב) ושום דבר אחר לא משתנה.

| קובץ | מתי משתמשים |
|---|---|
| `lizzy-wave.svg` | דף הבית (Hero), ברכת "ברוכה הבאה" |
| `lizzy-reading.svg` | קורא הספר, לשונית "צפייה בספר" |
| `lizzy-shopping.svg` | קטלוג, עגלה (גם עגלה ריקה) |
| `lizzy-happy.svg` | אחרי שליחת הזמנה, אחרי שליחת פנייה, הזמנה אושרה |
| `lizzy-confused.svg` | עמוד 404, שגיאות, "לא נמצאו תוצאות", קישור הורדה שפג |
| `lizzy-sleepy.svg` | מצב טעינה ארוך (השרת החינמי "מתעורר") |
| `lizzy-face.svg` | לוגו קטן, Favicon, אווטאר בכותרת האתר |

- כל הקבצים נגזרים מאותה פלטה: ורוד `#FF8FC1`, תכלת `#8FD3F4`, חום שיער `#7B4A2B`.
- כל קובץ כולל `<title>` נגיש. בשימוש בתוך `<img>` תני `alt` בשפה הנוכחית; כשהדמות רק קישוט – `alt=""`.
- הדמות לא "מתהפכת" ב-RTL (אין בה טקסט). אפשר להפוך אופקית (`transform: scaleX(-1)`) כדי שתביט פנימה למרכז הדף בעברית.
